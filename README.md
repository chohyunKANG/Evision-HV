## 🚀 0주차: Git & GitHub (선택 과제)

인원이 많은 프로젝트에서 협업하려면 git은 필수입니다.
0주차에는 git과 GitHub가 무엇인지, 실제로 어떻게 쓰는지, 코드를 작성할 때 어떻게 활용하는지 직접 해 보면서 익힙니다.

> 📌 **0주차는 선택 과제입니다.** 하지 않아도 경고는 없지만, 프로젝트 기간에는 협업을 GitHub로 진행하므로 **가능하면 모두 한 번씩 따라와 보는 것을 권장합니다.**
>
> 특히 이런 분은 꼭 해 보세요.
> - GitHub를 사용해 본 적이 없다
> - 사용해 봤지만 제대로 이해하고 쓰고 있는지 잘 모르겠다
> - push, pull 같은 기본 작업을 AI 없이는 하기 어렵다
